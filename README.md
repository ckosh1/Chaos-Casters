Chaos-Casters:
A fantasy action game developed in Unity during a week-long EA Orlando summer program.

About:
Chaos-Casters is a playable fantasy action game developed by a four-person student team. The game features two playable wizards, each with three spells, along with player movement, health systems, animations, audio, and an interactive environment.


This repository is my personal portfolio copy of the collaborative project. It is presented to document my work and contributions to the project.


Features: 
- Two playable wizards
- Three spells for each wizard
- Player movement and controls
- Health system
- Combat/gameplay mechanics
- Interactive environment
- Character animations
- Audio and sound effects


Technologies
- Unity
- C#


My Contributions
- Created the Environment using free environment assets from Unity Store. I created barriers of rocks to restrict the domain of the game space.
- Developed the movement for both characters. I added animations too.
- Added animations for the spells, and the characters' animations casting the spells.


Collaboration
This project was developed with three other students as part of a week-long EA Orlando summer program. We collaborated on the design and development of the game, with each team member contributing to different aspects of the project.
